# دعوة خطوبة محمود وندى

ملفات موقع ثابت مجاني، متجاوب مع الموبايل، بتصميم أسود وذهبي.

## المعاينة
افتح `index.html` في المتصفح لمعاينة الموقع محليًا.

## النشر المجاني باستخدام GitHub Pages
1. سجّل الدخول إلى https://github.com/ أو أنشئ حسابًا مجانيًا.
2. أنشئ مستودعًا جديدًا (New repository) باسم `mahmoud-nada-engagement` واجعله Public.
3. ارفع ملف `index.html` إلى جذر المستودع باستخدام Add file → Upload files ثم Commit changes.
4. افتح Settings → Pages.
5. في Build and deployment اختر `Deploy from a branch`.
6. اختر Branch: `main` والمجلد `/ (root)` ثم اضغط Save.
7. انتظر اكتمال النشر، ثم افتح الرابط الذي يظهر في صفحة Pages. غالبًا يكون بالشكل:
   `https://YOUR-USERNAME.github.io/mahmoud-nada-engagement/`
8. انسخ الرابط النهائي وأرسله على واتساب. قد يستغرق النشر عدة دقائق.

## التعديل
- الأسماء والتاريخ والساعة والمكان موجودة داخل `index.html`.
- رابط الخريطة يبحث عن Acacia في مصر؛ إذا كان عندك رابط Google Maps الدقيق للمكان، استبدل قيمة `href` الخاصة بالزر `mapsBtn`.
- الوقت الحالي مضبوط على 15 أكتوبر 2026 الساعة 9 مساءً بتوقيت القاهرة.
- الموقع يستخدم خطي Google Fonts عند توفر الإنترنت، ويظل قابلًا للعرض إذا تعذر تحميل الخطوط.

ملاحظة: رابط عام قابل للمشاركة لا يتكوّن إلا بعد رفع الملفات ونشرها على منصة الاستضافة.
